```bash

npm run build      # Production build into build/
npm run serve      # Serve the production build locally
npm run typecheck  # TypeScript type check (no emit)
npm run clear      # Clear Docusaurus cache (.docusaurus/ and build/)
```

## Architecture

This is a [Docusaurus 3](https://docusaurus.io) documentation site for the IntelliKeep Home Assistant integration, written in TypeScript with the classic preset.

**Key files:**
- `docusaurus.config.ts` — site config: URL, navbar, footer, plugins, theme
- `sidebars.ts` — sidebar is fully autogenerated from `docs/` folder structure
- `src/css/custom.css` — global CSS overrides, brand colors and theme variable overrides
- `docs/intro.md` has `slug: /`, so it is the site's home page (there is no `src/pages/`)

**Docs structure (`docs/`):**
Sidebar order and nesting are controlled by `sidebar_position` frontmatter and directory hierarchy. The sidebar is autogenerated — no manual sidebar entries needed.

**Versions and translations:**
- `docs/` is the unreleased "Next" version. The newest entry in `versions.json` is served at the root; cut a version at each IntelliKeep release with `npm run docusaurus docs:version <version>` (copies `docs/` and the `i18n/*/…/current` translations).
- Locales `pt-BR` and `es` live in `i18n/<locale>/docusaurus-plugin-content-docs/current/`, mirroring `docs/`. Translated headings that are link targets carry an explicit English ID so anchors work in every locale. Use the comment form `## Tarefas recorrentes {/* #recurring-tasks */}`: `future.v4` turns off MDX 1 compatibility, so `{#id}` fails to compile.
- Use the product's own UI wording in translations: `../intellikeep/panel/src/translations.ts`, `../intellikeep/lovelace-card/src/translations.ts` and `../intellikeep/custom_components/intellikeep/translations/`.

**Conventions:**
- All navigation items (navbar labels, sidebar category labels, page titles) must start with an uppercase letter.
- Sidebar category labels for subdirectories are set via `_category_.json` files (`label` field).
- Screenshots are embedded as `<img src={require('@site/static/img/screenshots/<file>.png').default} alt="…" className="ik-screenshot" />` (add `ik-screenshot--phone` or `ik-screenshot--card` for narrow images).

**Brand assets (`static/img/`)**, sourced from `../intellikeep/brand/` and `../intellikeep/.github/images/`:
- Navbar wordmark: `logo.png` (light) and `logo-dark.png` (dark), resized from `logo@2x.png` / `dark_logo@2x.png` to 128px tall
- Icon: `icon.png`, `icon-dark.png`, `icon.svg`; `favicon.ico` is generated from `icon@2x.png` (16/32/48px)
- `social-card.png` is the README banner; `screenshots/` holds the README screenshots
- Brand colors: teal `#133A43`, green `#12A37F` (light theme), mint `#5EE6A8` (dark theme)
